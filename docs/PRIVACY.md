# Приватность

babushkin-jam — неофициальное расширение для Chrome. Оно позволяет нескольким людям слушать Яндекс Музыку синхронно и не связано с ООО «Яндекс».

Полная политика конфиденциальности (на русском и английском), которую видит Chrome Web Store, лежит в [`services/rooms/privacy.html`](../services/rooms/privacy.html). Сервер отдаёт её по адресу `/privacy`.

## Что отправляется на сервер

Только пока вы находитесь в комнате джема:

- имя, которое вы указали (по умолчанию — случайное название животного);
- код комнаты;
- текущий трек: название, исполнитель, альбом, обложка, идентификаторы трека и альбома в Яндекс Музыке, длительность;
- состояние воспроизведения: позиция, пауза или воспроизведение, следующий трек.

Сервер пересылает эти данные остальным участникам той же комнаты, чтобы их плеер включил тот же трек на той же позиции.

## Что не собирается

- Логины, пароли, cookies, данные аккаунта и подписки Яндекса.
- История посещений и действия на других сайтах. Плеером и джемом расширение управляет только на `music.yandex.*`. Если включить «Виджет на всех сайтах», на других сайтах появится виджет, но он не читает страницу и ничего с неё не отправляет.
- Платёжные данные, контакты, местоположение.

Чтобы узнать идентификатор играющего трека, расширение читает ответы сайта Яндекс Музыки внутри вашей вкладки. Они обрабатываются только на вашем устройстве и никуда не отправляются.

## Хранение

- Сервер хранит состояние комнаты только в оперативной памяти — без базы данных и журналов. Пустая комната удаляется через 5 минут после выхода последнего участника, перезапуск сервера стирает все комнаты.
- Имя, код комнаты, адрес сервера и положение виджета хранятся локально в вашем браузере (`chrome.storage.local`).
- В приложении плейлист, текущий трек и время хранятся только на вашем компьютере (`playback.json`). Это отключается в настройках, там же есть кнопка сброса.
- Данные не продаются, не передаются третьим лицам и не используются для рекламы или аналитики.

## Сервис ссылок на песню

В приложении кнопка «Уйти на сайт» открывает в браузере страницу сервиса ссылок. В её адресе есть исполнитель, название, альбом, длительность и номер трека. Расширение и приложение сами туда ничего не отправляют.

Текст запроса сервис передаёт внешним площадкам для поиска: Apple, Deezer, YouTube, SoundCloud и другим подключённым. Результаты поиска с текстом запроса хранятся в кэше на сервере до 30 дней. IP-адрес используется только в памяти для ограничения частоты запросов. В журналы сервис не пишет ни адреса, ни запросы.

## Обновления приложения

Приложение проверяет новую версию запросом к GitHub и скачивает её оттуда же, поэтому GitHub видит ваш IP-адрес. Никаких данных о вас, комнате или музыке в этом запросе нет. Расширение таких запросов не делает, его обновляет Chrome.

## Комнаты не защищены паролем

Кто знает код комнаты, тот может в неё войти. Код из 6 символов сложно угадать, но не отправляйте ссылку-приглашение туда, где её увидят посторонние.

## Свой сервер

Если не хотите пользоваться общим сервером, поднимите свой ([SELF_HOSTING.md](SELF_HOSTING.md)) и впишите его адрес в поле «Сервер» в попапе.
