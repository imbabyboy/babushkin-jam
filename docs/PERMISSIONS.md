# Разрешения

Расширение просит минимум. Всё перечислено в [`extension/manifest.json`](../extension/manifest.json).

| Разрешение | Зачем |
| --- | --- |
| `storage` | Хранить в браузере ваше имя, код комнаты, адрес сервера, положение виджета и скрыт ли он. |
| Доступ к `https://*.music.yandex.ru/*`, `.com`, `.by`, `.kz` | Показывать виджет «Джем», читать состояние плеера и управлять им. |
| `scripting` | Показывать виджет на других сайтах, если вы включили это в настройках (см. ниже). Без доступа ко всем сайтам ничего не делает. |
| Доступ ко всем сайтам — **необязательный** (`optional_host_permissions`) | Только для настройки «Где показывать виджет → На всех сайтах». При установке не запрашивается: Chrome спросит его один раз, когда вы выберете эту настройку. Если потом вернуть «На Яндекс Музыке», скрипт виджета перестаёт встраиваться в сайты, а само разрешение остаётся, чтобы при повторном включении не спрашивать снова. Отозвать его совсем: `chrome://extensions` → babushkin-jam → «Сведения» → «Доступ к сайтам». |

### Виджет на всех сайтах

Если включить, на каждом сайте (кроме Яндекс Музыки) появляется тот же виджет «Джем»: кто в комнате, кнопки плеера, создать комнату или войти. Скрипт виджета (`extension/src/remote.js`) не читает страницу и ничего с неё не берёт: он только рисует виджет в своём Shadow DOM и раз в секунду, пока вкладку видно, спрашивает состояние у вкладки Яндекс Музыки через фоновый скрипт расширения (`extension/src/background.js`). Сам джем по-прежнему работает только во вкладке Яндекс Музыки.

Фоновый скрипт нужен только для этого: передать запрос виджета во вкладку Яндекс Музыки, переключиться на неё (чтобы включить звук) и зарегистрировать или снять скрипт виджета вслед за настройкой (и разрешением).

Шрифты интерфейса (`fonts/*.woff2`) объявлены в `web_accessible_resources` для всех сайтов: иначе виджет не сможет их загрузить. Других файлов расширения страницы не видят.

Чего у расширения **нет**: доступа к истории, cookies, загрузкам; без включённой настройки — доступа к сайтам, кроме Яндекс Музыки.

## Скрипт в контексте страницы

Один из скриптов (`extension/src/page.js`) запускается в контексте самой страницы Яндекс Музыки (`world: "MAIN"`) до загрузки сайта. Так он успевает увидеть аудиоэлемент плеера, обработчики кнопок Media Session и ответы API сайта с данными треков. Это нужно, чтобы узнать, какой трек играет, и включить нужный трек у остальных участников.

Этот скрипт ничего не отправляет в сеть. Он передаёт состояние плеера второму скрипту расширения через `window.postMessage`, и только тот общается с сервером джема.

## Сеть

Расширение открывает одно WebSocket-соединение — с сервером джема, адрес которого указан в попапе. Ещё попап, пока открыт, на секунду подключается к тому же серверу, чтобы показать «на связи» или «нет связи». Других запросов расширение не делает: шрифты лежат внутри него, а не грузятся с Google Fonts.
