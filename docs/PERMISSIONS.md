# Разрешения

Расширение просит минимум. Всё перечислено в [`extension/manifest.json`](../extension/manifest.json).

| Разрешение | Зачем |
| --- | --- |
| `storage` | Хранить в браузере ваше имя, код комнаты и адрес сервера. |
| Доступ к `https://*.music.yandex.ru/*`, `.com`, `.by`, `.kz` | Показывать панель «🎧 Джем», читать состояние плеера и управлять им. На других сайтах расширение не работает. |

Чего у расширения **нет**: доступа ко всем сайтам, к вкладкам и истории, к cookies, к загрузкам, фонового service worker.

## Скрипт в контексте страницы

Один из скриптов (`extension/src/page.js`) запускается в контексте самой страницы Яндекс Музыки (`world: "MAIN"`) до загрузки сайта. Так он успевает увидеть аудиоэлемент плеера, обработчики кнопок Media Session и ответы API сайта с данными треков. Это нужно, чтобы узнать, какой трек играет, и включить нужный трек у остальных участников.

Этот скрипт ничего не отправляет в сеть. Он передаёт состояние плеера второму скрипту расширения через `window.postMessage`, и только тот общается с сервером джема.

## Сеть

Расширение открывает одно WebSocket-соединение — с сервером джема, адрес которого указан в попапе. Других запросов оно не делает.
