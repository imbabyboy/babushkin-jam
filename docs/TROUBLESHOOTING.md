# Решение проблем

Сначала откройте попап расширения (значок на панели Chrome). Там видно, подключены ли вы и кто ведущий. Под гаечным ключом — пинг до сервера, ваше расхождение с комнатой, версия состояния комнаты и кнопки «Синхронизировать» и «Скопировать диагностику».

## Частые проблемы

**Плашка «Джем» стала жёлтой: «Нажмите, чтобы включить звук».**
Chrome не даёт включать звук, пока по вкладке никто не кликнул. Кликните по плашке — плеер подстроится под комнату.

**Плашки «Джем» нет на странице / попап пишет, что вкладка не найдена.**
Вкладка была открыта до установки или обновления расширения. Перезагрузите её.

**«У ведущего не определился id трека — включите вручную».**
Расширение ведущего не смогло узнать, какой именно трек играет. Включите этот трек вручную; если повторяется, пришлите диагностику с компьютера ведущего.

**«Не получилось включить … — включите вручную».**
Три попытки включить трек не удались. Чаще всего трека нет в подписке или регионе этого участника. Включите трек вручную или в попапе нажмите гаечный ключ → «Синхронизировать».

**Трек тот же, но позиция всё время прыгает.**
В попапе: гаечный ключ → «Синхронизировать». Если повторяется — проверьте, что Яндекс Музыка открыта только в одной вкладке: каждая вкладка входит в комнату отдельным участником.

**После перезагрузки страницы заиграл другой трек.**
Если в комнате есть кто-то ещё, вы подстраиваетесь под комнату. Если вы в комнате один, наоборот, комната подстраивается под ваш трек.

**«Подключение…» не проходит.**
Проверьте адрес в поле «Сервер» в попапе. Пустое поле — сервер по умолчанию. Для своего сервера адрес должен начинаться с `wss://` (или `ws://localhost` для локального).

## Диагностика для баг-репорта

Попап → гаечный ключ → «Скопировать диагностику». В буфер попадёт JSON: что расширение нашло на странице (аудиоэлементы, обработчики плеера, id трека из разных источников, последние сетевые запросы сайта) и состояние джема (соединение, комната, ведущий, смещение часов). Приложите его к [issue](https://github.com/imbabyboy/babushkin-jam/issues/new/choose).

## Консоль страницы

На music.yandex.ru откройте F12 → Console. Расширение добавляет объект `ymJam`:

```js
ymJam.diag()                           // то же, что «Скопировать диагностику», без данных джема
ymJam.state()                          // трек, позиция, пауза, следующий трек
ymJam.pause(); ymJam.play()
ymJam.seek(60)                         // перемотать на 60 секунд
ymJam.next(); ymJam.prev()
ymJam.playTrack('<id трека>', '<id альбома>')
```

Что смотреть в `diag()`:

| Поле | Если плохо |
| --- | --- |
| `media` пустой | расширение не нашло аудиоэлемент плеера |
| `handlers` пустой | сайт не регистрирует кнопки Media Session — управление идёт напрямую через `<audio>` |
| `track.id: null` | id не определился; смотрите `idCandidates`, `fileInfo`, `playerLinks` |
| `trackPlayButtons` пустой на странице трека | у сайта поменялась вёрстка кнопок |

## Проверка на одном компьютере

Два профиля Chrome, в каждом загружено расширение, оба входят в одну комнату.

## Разведка устройства плеера

[`tools/ym-probe.js`](../tools/ym-probe.js) — отдельный скрипт для консоли, с которого начинался проект. Он перехватывает аудиоэлементы, Media Session и сетевые запросы сайта и печатает отчёт `ymProbe.report()`. Пригодится, если сайт сильно изменился и нужно заново понять, как устроен плеер.
