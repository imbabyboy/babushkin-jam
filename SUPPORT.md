# Поддержка

- **Что-то не работает** — сначала [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- **Нашли баг** — [откройте issue](https://github.com/imbabyboy/babushkin-jam/issues/new/choose) по шаблону и приложите отчёт из попапа (гаечный ключ → «Скопировать диагностику»).
- **Есть идея** — тоже issue, шаблон «Идея».
- **Отзыв или оценка** — на [странице в Chrome Web Store](https://chromewebstore.google.com/detail/babushkin-jam/iincaikpjidieflnaajiehogcimgbepe).
- **Уязвимость** — не в публичный issue, см. [SECURITY.md](SECURITY.md).

Проект делается в свободное время, так что ответ может занять несколько дней.

Это неофициальное расширение: по вопросам подписки, аккаунта и работы самой Яндекс Музыки обращайтесь в поддержку Яндекса.
