# babushkin-jam

Неофициальное расширение для Chrome (не связано с Яндексом): несколько человек слушают Яндекс Музыку синхронно, каждый в своём браузере. Кто переключил трек, тот ведущий; пауза и перемотка от любого участника применяются ко всем.

Состоит из двух частей:

- `server/` — сервер комнат (Node.js + WebSocket);
- `extension/` — расширение для Chrome;
- `store/` — тексты и картинки для Chrome Web Store (`store/listing.md`).

Подробности и договорённости — в «Джем для Яндекс Музыки контекст проекта.md».

## 1. Сервер

Нужен Node.js 18 или новее.

```bash
cd server
npm install      # один раз
npm start        # запуск
npm run dev      # запуск с перезапуском при изменении кода
```

Сервер слушает `ws://localhost:8787`. Другой порт: `PORT=9000 npm start`. Локальный сервер нужен для разработки: чтобы расширение ходило к нему, впишите `ws://localhost:8787` в поле «Сервер» в попапе.

**Из VS Code:** `Cmd+Shift+B` запускает сервер в режиме watch. Остальные задачи — `Cmd+Shift+P` → «Tasks: Run Task»:

- «Сервер: watch» — то же, что `npm run dev`;
- «Сервер: установить зависимости» — `npm install`;
- «Расширение: собрать zip» — `dist/babushkin-jam.zip` для Chrome Web Store и друзей.

## 2. Расширение

Собирать ничего не нужно: Chrome загружает папку `extension/` как есть.

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель справа вверху).
3. «Загрузить распакованное» → выберите папку `extension/`.
4. Перезагрузите вкладку music.yandex.ru, если она была открыта.

После правок в коде нажмите ↻ у расширения в `chrome://extensions` и перезагрузите вкладку Яндекс Музыки. Если меняли только попап, вкладку перезагружать не нужно.

Чтобы отправить расширение другу: задача «Расширение: собрать zip» (или `cd extension && zip -r ../dist/babushkin-jam.zip .`). Друг распаковывает архив и загружает папку так же, по шагам выше.

## 3. Как пользоваться

Всё уже настроено: сервер прописан, имя выбирается случайно («Суслик», «Волк»…). Нажимать на значок расширения не нужно — всё делается в панели «🎧 Джем» в правом нижнем углу Яндекс Музыки.

**Создать джем:**
1. Откройте music.yandex.ru, нажмите «🎧 Джем» → «Создать комнату».
2. Нажмите «Скопировать ссылку» и отправьте её друзьям.
3. Включите трек — станете ведущим, у остальных включится то же самое.

**Присоединиться:** откройте ссылку от друга (вида `https://music.yandex.ru/?jam=N78X65`) — панель откроется сама, останется нажать «Войти в джем». Или «🎧 Джем» → ввести код → «Войти».

Если кнопка панели стала жёлтой, кликните по ней: Chrome не даёт включать звук, пока по вкладке никто не кликнул.

Попап расширения (значок на панели Chrome) тоже работает: там же можно сменить имя и сервер, посмотреть состояние сервера и скопировать диагностику.

**Тест на одном компьютере:** два профиля Chrome, в каждом загружено расширение, оба входят в одну комнату.

## Общий сервер (VPS)

Сервер джема работает на VPS `141.11.197.57` в Docker: контейнер `yandex-jam` (Node) и `yandex-jam-caddy` (Caddy: HTTPS и сертификат Let's Encrypt для `141-11-197-57.sslip.io`). Порт 443 на VPS занят VPN, поэтому адрес — с портом 8443:

```
wss://141-11-197-57.sslip.io:8443
```

Обновить сервер после правок в `server/`:

```bash
sh deploy/deploy.sh
```

Скрипт копирует файлы в `/opt/yandex-jam`, пересобирает образ и перезапускает контейнер. Логи: `ssh root@141.11.197.57 docker logs -f yandex-jam`.

## Публикация в Chrome Web Store

Всё для загрузки собрано в `store/listing.md`: описание, обоснования разрешений, ответы для формы о данных, ссылка на политику конфиденциальности (`/privacy` на сервере). Видимость — Unlisted (по ссылке) или Private (по почтам).

## Отладка

- В попапе блок с состоянием сервера: трек и его id, время, пауза или плей, следующий трек, ваше расхождение с сервером, версия состояния.
- «Скопировать диагностику» в попапе — что расширение нашло на странице: аудиоэлементы, обработчики плеера, id трека, сетевые запросы.
- В консоли страницы (F12): `ymJam.diag()`, `ymJam.state()`, `ymJam.pause()`, `ymJam.play()`, `ymJam.seek(60)`, `ymJam.next()`, `ymJam.playTrack('<id трека>', '<id альбома>')`.

## Ограничения

- Всё, что касается плеера (`extension/src/page.js`), — догадки: на живом сайте ещё не проверялось.
- Очередь ведущего не читается, поэтому «следующий трек» пока всегда пустой.
- Каждая открытая вкладка Яндекс Музыки входит в комнату отдельным участником — держите одну.
- У каждого участника нужна своя подписка; если трека у кого-то нет, у него синхронизация не сработает.
