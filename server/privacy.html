babushkin-jam: политика конфиденциальности

Обновлено 6 октября 2026

babushkin-jam — неофициальное расширение для Chrome. Оно позволяет нескольким людям слушать Яндекс Музыку синхронно. Расширение не связано с ООО «Яндекс» и не одобрено им.

Что отправляется на сервер

Только пока вы находитесь в комнате джема, расширение отправляет на сервер джема:

  • имя, которое вы указали (по умолчанию случайное название животного);
  • код комнаты;
  • текущий трек: название, исполнитель, альбом, обложка, идентификаторы трека и альбома в Яндекс Музыке, длительность;
  • состояние воспроизведения: позиция, пауза или воспроизведение, следующий трек.

Сервер передаёт эти данные остальным участникам той же комнаты, чтобы их плеер включил тот же трек на той же позиции.

Что не собирается

  • Логины, пароли, cookies, данные аккаунта и подписки Яндекса.
  • История посещений и действия на других сайтах: расширение работает только на music.yandex.*.
  • Платёжные данные, контакты, местоположение.

Чтобы узнать идентификатор играющего трека, расширение читает ответы сайта Яндекс Музыки внутри вашей вкладки. Эти ответы обрабатываются только на вашем устройстве и никуда не отправляются.

Хранение

Сервер хранит состояние комнаты только в оперативной памяти, без базы данных и журналов. Пустая комната удаляется через 5 минут после выхода последнего участника. Имя, код комнаты и адрес сервера хранятся локально в вашем браузере (chrome.storage).

Данные не продаются, не передаются третьим лицам и не используются для рекламы или аналитики.

Контакты

Вопросы можно задать через страницу расширения в Chrome Web Store (раздел «Поддержка»).

babushkin-jam: privacy policy

Updated October 6, 2026

babushkin-jam is an unofficial Chrome extension that lets several people listen to Yandex Music in sync. It is not affiliated with or endorsed by Yandex.

Data sent to the server

Only while you are in a jam room, the extension sends to the jam server:

  • the display name you chose (a random animal name by default);
  • the room code;
  • the current track: title, artist, album, cover URL, Yandex Music track and album IDs, duration;
  • playback state: position, paused or playing, next track.

The server relays this data to the other members of the same room so their player can play the same track at the same position.

Data not collected

  • Logins, passwords, cookies, Yandex account or subscription data.
  • Browsing history or activity on other sites: the extension only runs on music.yandex.*.
  • Payment data, contacts, location.

To learn the ID of the playing track, the extension reads Yandex Music responses inside your tab. They are processed on your device only and are never sent anywhere.

Retention

The server keeps room state in memory only, with no database or logs. An empty room is deleted 5 minutes after the last member leaves. Your name, room code and server address are stored locally in your browser (chrome.storage).

Data is not sold, not shared with third parties and not used for advertising or analytics.

Contact

Questions can be asked via the extension page in the Chrome Web Store (Support tab).
