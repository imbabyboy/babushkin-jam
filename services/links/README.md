# Сервис ссылок на песню

По названию находит песню на разных площадках и показывает ссылки одной страницей. Музыку не скачивает и не хранит. Требования и решения — в [ТЗ](../../docs/SONG_LINKS_TZ.md).

## Запуск и проверка

Нужен Node.js 22.13 или новее, зависимостей нет.

```bash
cd services/links
npm start      # http://localhost:8790
npm test       # без сети, на записанных и подставных ответах
npm run record # заново записать ответы Apple и Deezer для эталонного набора
```

Настройки и ключи — переменные окружения, список в [`.env.example`](.env.example). Деплой описан в [docs/SELF_HOSTING.md](../../docs/SELF_HOSTING.md#сервис-ссылок-на-песню).

## Параметры

`/?singer=kizaru&songname=trooper` сразу показывает результат. Ещё есть `q`, `album`, `year`, `duration` и `ym` (номер трека в Яндекс Музыке). `GET /api/search` принимает те же параметры и отдаёт JSON.

## Что показывает строка сервиса

| Вид | Значение |
| --- | --- |
| «Открыть» | найдена точная ссылка |
| `—` | сервис ответил, что песни нет |
| «Искать» | проверить не удалось: нет ключа, сбой, предел запросов или совпадения нет в начале выдачи |

## Откуда берутся данные

| Сервис | Способ |
| --- | --- |
| Apple Music, Deezer | открытый API без ключа |
| YouTube, SoundCloud | API, если есть ключ; без него страница поиска, только для песен |
| YouTube Music | страница поиска |
| Spotify | API, нужен ключ; на живом API не проверено |
| Яндекс Музыка | только ссылка из `ym`, поиск с нашего VPS отвечает `451` |

Разбор страниц поиска противоречит условиям YouTube. Условия SoundCloud и YouTube Music отдельно не проверялись, риск считаем таким же. Сервисы могут заблокировать IP сервера, тогда останется «Искать». `PAGE_SEARCH=off` выключает разбор.

## Устройство

| Файл | Что делает |
| --- | --- |
| `server.js` | HTTP, лимиты, HTML с карточкой для Telegram |
| `search.js` | параллельный опрос сервисов, кэш, ответ |
| `match.js` | правила выбора результата: при сомнении лучше прочерк |
| `query.js` | разбор параметров |
| `cache.js` | кэш в SQLite и дневные пределы |
| `providers/` | по файлу на сервис |
| `public/` | страница |
